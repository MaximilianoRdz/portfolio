# Definición del Producto

## Propósito
Un portafolio web personal e interactivo para **Maximiliano Rodríguez**, diseñado para exhibir de manera profesional su experiencia, proyectos destacados y stack tecnológico como desarrollador Full Stack.

## Público Objetivo
- Reclutadores y Talent Acquisition del sector IT.
- Clientes potenciales interesados en servicios de desarrollo web y software a medida.
- Colegas y desarrolladores de la comunidad tecnológica.

## Características y Secciones Clave
1. **Hero (Inicio)**: Presentación impactante con el nombre, título profesional ("Ingeniero en Tecnologías de la Información") y un claro Llamado a la Acción (CTA) para descargar el currículum vitae.
2. **Sobre Mí**: Una biografía profesional concisa, enfocada en la filosofía de desarrollo y la creación de soluciones escalables con arquitectura limpia.
3. **Trayectoria (Experiencia)**: Una línea de tiempo visual que detalla experiencia laboral formal y formación académica relevante.
4. **Proyectos**: Galería de trabajos destacados presentados en tarjetas ("cards") que incluyen una descripción, el stack tecnológico utilizado (tags) y enlaces directos a demos o repositorios.
5. **Habilidades**: Una cuadrícula que consolida visualmente los lenguajes, frameworks y herramientas que el desarrollador domina, utilizando iconos representativos.

## Objetivos del Negocio (Personal Branding)
- Transmitir modernidad, calidad de código y atención al detalle a través de una UI sumamente pulida.
- Proveer métodos de contacto rápidos y directos (enlaces a LinkedIn, GitHub y correo electrónico).
